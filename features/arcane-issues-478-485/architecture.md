# Architecture

Related: [[PRD]] and [[DECISIONS]]

1. Keep the interactive sign-off rules in one shared spell fragment. Generate the installed copies and keep the provider reference linked to the shared rules. Keep a run grant, an interactive vote, and the completion decision independently scoped.
2. Add an ended grant state to the existing parser and evaluator. An ended record denies all actions. Plan a human delivery checkpoint if turning the record terminal removes the authority needed to deliver it. Verify the terminal record on trunk after completion.
3. Let doctor scan supported instruction files for advisory language without executing any instruction. Use complete managed markers as the exclusion boundary. Report file, line, and gate without echoing file content.
4. Add the optional pair to the roster validator and carry the typed value through the effective state export. Preserve the shape of older roster entries. Add the field to the public state schema as optional.
5. Serialize the milestones that touch the same spells and pack all changes as one release. Exercise regressions in grant evaluation, doctor, roster loading and state serialization, then run the repository gates.
