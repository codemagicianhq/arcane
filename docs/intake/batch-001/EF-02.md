## Claim

Canonical spells reference operator documents at root-level paths even though `spell init` installs the corresponding framework files under `.arcane/governance/`, leaving an unresolved one-layer versus two-layer document model.

## Verification

Confirmed. The registry installs governance files under `.arcane/governance/`, including development methodology and agent policies, at [registry.ts](../../../src/modules/registry.ts#L13-L20) and [registry.ts](../../../src/modules/registry.ts#L61-L68). Canonical prompts nevertheless reference root-level paths, for example [spell-architect.prompt.md](../../../src/assets/.github/prompts/spell-architect.prompt.md#L21-L22), [spell-enchant.prompt.md](../../../src/assets/.github/prompts/spell-enchant.prompt.md#L23-L28), and [spell-bootstrap-business.prompt.md](../../../src/assets/.github/prompts/spell-bootstrap-business.prompt.md#L26-L30). Other prompts use the installed dotted path, for example [spell-address-review.prompt.md](../../../src/assets/.github/prompts/spell-address-review.prompt.md#L22-L23).

The submitted counts do not reproduce. Current raw line matches are 21 for `governance/development-methodology.md`, 15 for `project.md`, 13 for testing standards, 17 for git conventions, 11 for agent policies, 8 for README, 4 for threat model, and 1 for the setup playbook. The batch appears to mix line-occurrence and unique-file counts.

## Impact

Spells routinely take fallback paths even when the required framework document was installed elsewhere. Operators cannot tell whether they should edit vendored `.arcane/` files or create separate root-level project instances.

## Proposed fix

Decide and document one ownership model before changing paths: either a single managed `.arcane/` layer referenced by every spell, or a two-layer model where `.arcane/` contains templates and `spell init` scaffolds operator-owned instances. Include a discoverable "Where documents live" section.

## Open questions

Are files under `.arcane/governance/` intended to be edited project instances, immutable vendor content, or defaults copied into an operator-owned layer?
