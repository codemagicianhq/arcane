## Claim

`.arcane.json` has no configuration section even though attribution, subject-location, and tracker workflows all instruct agents to resolve persistent settings from it. This is one schema defect, not three field requests.

## Verification

Confirmed as one merged finding. `ArcaneManifest` contains only `version`, `profile`, `installedAt`, and `components` at [types.ts](../../../src/types.ts#L12-L17), and `runInit` writes exactly those fields at [init.ts](../../../src/commands/init.ts#L272-L279). There is no configuration prompt before the manifest is written.

Current readers include `{OPERATOR_DOMAIN}` in [spell-commit-work.prompt.md](../../../src/assets/.github/prompts/spell-commit-work.prompt.md#L55-L62), tracker settings and repository lists in [spell-open-session.prompt.md](../../../src/assets/.github/prompts/spell-open-session.prompt.md#L63-L69), and business-root settings in [spell-bootstrap-business.prompt.md](../../../src/assets/.github/prompts/spell-bootstrap-business.prompt.md#L32-L36). Seven canonical spells read tracker mode/provider settings. The identity registry still contains unresolved domain placeholders at [git-conventions.md](../../../src/assets/.arcane/governance/git-conventions.md#L530-L541).

## Impact

Persistent choices remain in the operator's head. Spells repeatedly ask, silently infer defaults, or operate against missing values. Independent patches would create incompatible ad-hoc shapes and make updates unsafe.

## Proposed fix

Define and publish one versioned configuration schema covering operator identity, subject/business roots, tracking mode/provider, provider coordinates, and repository lists. Then make `spell init` populate it once and `spell update` backfill missing schema versions without overwriting user values. Generate agent identity data from the configured roster and identity domain.

## Open questions

Should user-owned configuration live inside `.arcane.json` or in a separate file with a distinct update lifecycle? Which fields are repository-level versus operator-level, and how are secrets prohibited from this schema?
