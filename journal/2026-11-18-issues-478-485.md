### Lessons Learned

#### Use Node’s import hook when the Codex sandbox denies tsx IPC

The stale-claims check failed to bind the temporary socket used by the `tsx` launcher. On Node 24, `node --import tsx scripts/check-stale-claims.ts --check --report` ran the same checker successfully from the restricted shell. The open cross-client audit in [[TODO]] carries this observation and the test to reproduce it.

#### Verify GitHub auth from a network-capable shell

The first sandboxed check made the token look invalid. The same account authenticated as `payini` from a network-capable execution surface. Check connectivity and identity together before diagnosing a credential problem. In a single-branch clone, check the remote topic SHA directly when the local fetch refspec tracks only trunk.

#### Confirm the published npm tarball after propagation

The npm publish step completed before the registry served the requested version to the operator’s environment. The workflow's downloadable-tarball check later passed, and a clean registry install succeeded. Record workflow completion and the installed-package smoke result as separate evidence.
